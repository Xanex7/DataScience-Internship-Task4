# Titanic Dataset – Mini Visualization Dashboard

This project is part of my **Data Science with Python Internship – Task 4**.

## Project Objective
Build a mini visualization dashboard to communicate key insights from the Titanic dataset using:
- Data Cleaning
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Data Storytelling through visualizations

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Cleaning Steps
- Filled missing Age values using median
- Filled missing Embarked values using mode
- Removed Cabin column due to excessive missing values

## Feature Engineering
- FamilySize = SibSp + Parch
- AgeGroup categorization

## Visualizations Included
- Histogram of Age Distribution
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Fare Distribution Boxplot
- Age vs Fare Scatterplot
- Correlation Heatmap

## Key Insights
- Female passengers had significantly higher survival rates
- First-class passengers had better survival outcomes
- Higher fares were associated with better survival chances
- Age and family size influenced passenger survival patterns
